# Runpod SDK Reference

Use this for the current Runpod SDK beta: remote GPU functions, app deployment, SDK endpoints, the `rp` CLI, runtime behavior, and migration from standalone Flash.

## Official sources

- Overview: `https://docs.runpod.io/sdk/overview`
- Quickstart: `https://docs.runpod.io/sdk/quickstart`
- CLI reference: `https://docs.runpod.io/sdk/cli`
- Runtime: `https://docs.runpod.io/sdk/runtime`
- Flash migration: `https://docs.runpod.io/sdk/migrate-from-flash`

## Routing

- Use the Runpod SDK for new local-code GPU applications and remote functions.
- Treat `runpod-flash` as legacy: the standalone Flash package stops receiving fixes and updates after October 29, 2026.
- Read the migration guide before translating `runpod_flash`, `Endpoint`, `GpuType`, or Flash CLI code.
- Refresh the official SDK docs before relying on beta CLI flags, decorators, resource configuration, or deployment behavior.
